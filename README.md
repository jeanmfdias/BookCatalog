# Catálogo de Livros

## Stack

* PHP 8.5.12
* Symfony 7.4 LTS
* Docker
* Postgresql 16

## Como executar

Criar o dotenv local `cp .env .env.dev`

Compilar os assets `npm run dev`

Via docker `docker compose --env-file .env.dev up -d`
